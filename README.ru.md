# BitTarget

[English](README.md) | **Русский**

![BitTarget](docs/logo2.png)

Симулятор крипто-торговли на Flutter. Данные рынка настоящие и живые (открытый API Binance), а деньги ненастоящие: есть демо-кошелёк, экран торговли с интерактивным графиком и стаканом заявок и обзор портфеля. Это проект для портфолио, в котором упор сделан на чистую архитектуру, данные в реальном времени и спокойную обработку сбоев.

## Возможности

### Главная
- Общий баланс считается из кошелька и живых цен, рядом эквивалент в BTC
- Карточка главной монеты с живым графиком и максимумом за 24 часа, монету можно менять в списке выбора
- Обзор рынка с мини-графиками, обновляется раз в несколько секунд
- Режим без сети: если связь пропала, остаются последние цены и появляется предупреждение
- Быстрые действия: пополнить, вывести, торговля (переход на вкладку «Торговля») и перевод
- Переключатель языка (русский и английский), который действует мгновенно

### Торговля
- Выбор пары с поиском, живыми ценами и избранным
- Интерактивный график: таймфреймы 15m / 1h / 4h / 1D, нажатие или проведение пальцем показывает точную цену и время, скользящая средняя (MA) и переключатель точек
- Живой стакан заявок через WebSocket с запасным запросом, если поток молчит
- Форма ордера: покупка и продажа, **лимитный** и **рыночный** ордера, кнопки 25/50/75/100%, предварительный итог, защита от цены дальше чем на 5% от рыночной
- Нажатие на цену в стакане подставляет её в форму
- Полоска «Переподключение...» и автоматическое переподключение; когда вкладка не видна, экран засыпает и не тратит трафик

### Кошелёк
- Оценка капитала и прибыль за 24 часа по живым ценам
- Кольцевая диаграмма структуры портфеля с легендой
- Пополнение (долларами или любой монетой), вывод (долларов), обмен (покупка и продажа крипты за доллары по рыночной цене) и перевод (отправка монеты на адрес с комиссией сети)
- История операций обновляется мгновенно от любых действий, включая сделки на вкладке «Торговля»

### Профиль
- Выход из аккаунта и вход. Пока пользователь вышел, навигация заблокирована: нижнее меню отключено, свайп между вкладками не работает

### Качество
- Общий сетевой слой: таймауты, одна автоматическая повторная попытка, понятные категории ошибок (нет связи, таймаут, ошибка сервера, лимит запросов) и кнопка «Повторить» везде, где данные не загрузились
- Деньги хранятся целыми числами (центы для долларов и миллионные доли для монет), поэтому ошибки округления не накапливаются
- Адаптивная вёрстка, которая переносит узкие экраны
- 41 модульный тест

## Технологии

| Область | Что использовано |
|---|---|
| Фреймворк | Flutter, Dart 3 |
| Управление состоянием | `flutter_bloc` (Cubit): рынок, торговля, кошелёк, язык, навигация и вход |
| Сеть | `dio` с общим клиентом и перехватчиком повторов; `web_socket_channel` для живых потоков |
| Источник данных | Открытые REST и WebSocket API Binance |
| Локализация | `flutter_localizations`, `intl`, ARB-файлы и `flutter gen-l10n` (русский и английский) |
| Интерфейс | Собственные виджеты, `CustomPainter` для графиков и кольца, карточки в стиле стекла, эффекты нажатия |
| Шрифты и иконки | `google_fonts` (Inter), иконки монет лежат в ассетах |
| Тесты | `flutter_test` с подставными сервисами вместо сети |

## Архитектура

Проект организован по функциям. В каждой функции **data** (откуда берутся данные) отделена от **presentation** (как они показываются), а между ними стоит Cubit.

```
API Binance -> сервис (Dio / WebSocket) -> Cubit (состояние) -> экраны и виджеты
```

```
lib/
├── main.dart                     запуск приложения, провайдеры
├── main_shell_screen.dart        нижнее меню, переключение страниц, блокировка при выходе
├── l10n/                         ARB-файлы и сгенерированные переводы
├── core/
│   ├── auth/  nav/  locale/      небольшие общие cubit
│   ├── network/                  ApiClient (таймауты, повторы, разбор ошибок)
│   ├── theme/  constants/        цвета, типографика
│   ├── utils/                    форматирование цен, фильтр ввода
│   └── widgets/                  стеклянная карточка, графики, эффект нажатия, общие виджеты
└── features/
    ├── home/                     data + presentation
    ├── trade/                    data + presentation
    ├── wallet/                   cubit, расчёт портфеля, presentation
    └── profile/
test/                             модульные тесты
assets/                           иконки монет и картинки
```

Решения, которые стоит отметить:

- **Один источник правды для рынка.** `MarketCubit` питает главную, оценку кошелька и списки монет.
- **Сбои продуманы заранее.** У каждого экрана, которому нужна сеть, есть состояния загрузки, ошибки и данных, действие «Повторить» и выход (например, выбор пары остаётся доступен на экране ошибки торговли).
- **Потоки за собой убирают.** WebSocket-соединения открыты только пока вкладка «Торговля» видна и закрываются, когда она скрыта.
- **Логика тестируется.** Cubit получают сервисы через конструктор, поэтому в тестах сеть заменяется подделками.

## Запуск

Нужны [Flutter SDK](https://docs.flutter.dev/get-started/install) и устройство, эмулятор или Chrome.

```bash
git clone https://github.com/YOUR_LOGIN/bittarget.git
cd bittarget
flutter pub get
flutter gen-l10n
flutter run -d chrome
```

Запуск тестов:

```bash
flutter test
```

В некоторых странах и сетях Binance может быть недоступен. Если цены не загружаются, приложение покажет ошибку с кнопкой «Повторить», а не зависнет.

## Тесты

41 тест покрывает:

- операции кошелька: пополнение, вывод, покупка, продажа, перевод, нехватка средств, округление, ограничение истории
- расчёт портфеля: капитал, прибыль за 24 часа, доли активов
- форматирование цен
- cubit рынка и торговли: загрузка, ошибки, повтор, смена монеты и таймфрейма
- блокировку при выходе и состояние навигации по вкладкам

## Планы

- Сохранение кошелька на устройстве и кнопка «Сбросить кошелёк»
